AI CFO COPILOT 1.0 — WINDOWS SETUP

1. Extract this ZIP into a normal folder such as Documents\AI CFO Copilot.
2. Copy your existing .streamlit folder into this folder so secrets.toml is retained.
3. Double-click start.bat.
4. The launcher creates/checks .venv and installs missing packages automatically.

KEY UPGRADES
- Drag the blue AI bot anywhere on the screen. Its position is remembered in that browser.
- Click the bot without dragging to open or close AI CFO.
- Use the sidebar Collapse control to switch to the compact icon rail.
- Import Centre and Company & Setup are placed near the top under Setup & Data.
- Upload the company logo during workspace creation; it is reused in board reports.
- Board Meeting provides a six-stage interactive director presentation mode.
- Dashboard begins with the personalised greeting and daily attention area.

PRIVATE FILES
The ZIP intentionally excludes .venv and .streamlit/secrets.toml.
