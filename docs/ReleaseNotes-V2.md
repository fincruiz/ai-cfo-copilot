# AI CFO Copilot — Enterprise UI V2

## What changed

- New persistent enterprise sidebar with clear workflow grouping and active-page state.
- New compact workspace top bar and contextual page headers.
- Unified dark finance design system across forms, tabs, buttons, metrics and tables.
- New executive KPI layer and action-focused dashboard summary.
- Restyled AI CFO as a compact Copilot drawer with smoother motion.
- Improved responsive behaviour for laptop, tablet and mobile widths.
- Refined login shell, workspace cards and onboarding dialogs.
- Added controlled page-entry, hover, pulse and drawer animations.

## What did not change

Finance calculations, mappings, reporting logic, sample data, AI services and research services remain intact.

## Run

Double-click `start.bat`, or run:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```
